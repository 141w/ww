# AI-Native Portfolio

个人 AI-Native 风格作品集网站。

## 技术栈

React 19 + Vite + TypeScript + TailwindCSS + Motion + Three.js + Lucide React

## 开发

```bash
npm run dev
```

## 构建

```bash
npm run build
```

## 推送

```bash
.\gitpush.ps1 "提交信息"
```

或手动：

```bash
git add -A
git commit -m "提交信息"
git push
```
